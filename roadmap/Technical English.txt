Module 2: Core Sentence Structure

โครงสร้างสำคัญที่สุดคือ

Subject + Verb + Object

ตัวอย่าง:

The system validates the input.
The API returns the result.
The user submits the form.
The service stores the data.
The application displays an error.

ต้องแยกให้ออกว่า

ใคร / อะไร + ทำอะไร + กับอะไร

ตัวอย่าง:

The authentication service verifies the access token.

Subject: the authentication service
Verb: verifies
Object: the access token
Module 3: Essential Grammar 80/20
3.1 Present Simple

ใช้บอกการทำงานทั่วไปของระบบ

The API receives a request.
The service validates the data.
The database stores user information.
3.2 Present Continuous

ใช้บอกสิ่งที่กำลังเกิดขึ้น

The server is processing the request.
I am investigating the issue.
We are updating the application.
3.3 Past Simple

ใช้รายงานสิ่งที่เกิดขึ้นแล้ว

The deployment failed.
I fixed the authentication bug.
The customer reported the issue.
3.4 Present Perfect

ใช้บอกว่างานเสร็จแล้วหรือเกิดขึ้นแล้ว

I have fixed the bug.
The system has completed the process.
We have deployed the new version.
3.5 Future
We will release the feature tomorrow.
I am going to update the API.
The team will review the pull request.
3.6 Modal Verbs
Modal	ความหมาย

should	ควร

may	อาจ
might	อาจจะ
need to	จำเป็นต้อง
have to	ต้อง

ตัวอย่าง:

The user must log in.

3.7 Passive Voice

พบมากใน Documentation และ Error

be + V3
The request was rejected.
The data is stored in the database.
The user must be authenticated.
The file has been deleted.
The service will be restarted.
3.8 Conditional
If the request fails, the system will retry.
If the token is invalid, the API returns 401.
If the value is null, use the default value.
If I had more time, I would refactor this module.
3.9 Relative Clauses
The service that handles authentication is unavailable.
The user who created the record can edit it.
The file that you uploaded is invalid.

Module 14: Requirement and User Story
User Story
As a [user],
I want [goal],
so that [benefit].

ตัวอย่าง:

As a warehouse employee,
I want to scan a material barcode,
so that I can retrieve its current inventory information.
Acceptance Criteria
Given [initial condition]
When [action]
Then [expected result]

ตัวอย่าง:

Given that the barcode exists,
when the employee scans it,
then the system displays the material information.
Business Rule
The quantity must be greater than zero.
Only authorized users can approve the request.

Module 18: Explaining a Bug

ใช้โครงสร้าง

Problem → Cause → Impact → Fix → Verification

ตัวอย่าง:

We found an issue in the inventory calculation.

The problem was caused by a nullable database column being converted directly to an integer.

As a result, the application crashed when the value was null.

I changed the property to a nullable integer and added a default-value check.

I also added unit tests to verify the null scenario.
